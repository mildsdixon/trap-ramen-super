# Trap Ramen — Super Version

The **Super Trap Street-Luxe** restaurant website for Trap Ramen in Clinton Township, Michigan.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The site includes a responsive menu, rotating promotion wall, campaign gallery, location, hours, Instagram link, and call-to-order actions.
